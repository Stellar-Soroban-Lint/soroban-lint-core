## When it fires

A binary arithmetic operator (`+ - * / %`) or a compound assignment where **both** operands carry integer evidence from syntax alone: an integer literal with a suffix (`10u64`), an explicit `as` cast to an integer type, an explicit integer annotation on the binding or parameter, or a `const`/`static` declared with an integer type. Division or modulo by a literal `0` is always flagged.

`wrapping_*`, `checked_*`, and `saturating_*` are not flagged, and floating-point arithmetic is not flagged.

Separately, when the path is a directory or a `Cargo.toml` is discoverable, the CLI emits one `SL003` on `Cargo.toml` if the release profile lacks `overflow-checks = true`.

## Examples

Flagged — both operands have integer evidence:

```rust
// warning: SL003, unchecked arithmetic
let next: u128 = count + 1;
```

Not flagged — the checked variant:

```rust
let next = count.checked_add(1).ok_or(Error::Overflow)?;
```

Not flagged — no syntactic integer evidence on the left operand, so the rule stays silent. This is the dominant false-negative mode, not a guarantee that the arithmetic is safe:

```rust
let total = env.storage().persistent().get(&Total) + amount;
```

## False positives and false negatives

**False positives.** Integer arithmetic that is bounded by a host invariant can still be reported; the rule cannot prove that external bound.

**False negatives.** Arithmetic without integer evidence in syntax, including values loaded from storage, is left unreported even when it can overflow.

## Suppressing this rule

Experimental and off by default, so most users enable it repository-wide rather than per line. If a specific site is guarded by a host invariant, name the rule on that line:

```rust
// soroban-lint-ignore: SL003 -- amount is bounded by the caller
let fee = base + amount;
```

## On the benchmark corpus

9 findings, all arguable, none confirmed false positives. Each one does carry genuine integer evidence; the argument is about whether the toy counters they appear in care about overflow. No true positives were recorded on this corpus.

Promotion to `stable` is deferred pending a larger, less toy-heavy corpus.
